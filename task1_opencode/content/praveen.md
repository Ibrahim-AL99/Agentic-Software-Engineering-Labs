## What I think about AI in software engineering today
AI agents are genuinely useful to be used as a hired clean code writer whose code has to be fully reviewed later but the architecture and the system design has to be totally by the humans.

## Where software engineering will be in 5–10 years
Agents will handle routine migrations, test maintenance, and dependency upgrades. Humans will spend more time on product decisions, system design, and verification. The job will not disappear, but the daily work will look different.

## My hot take on AI
The best code review and system design is still a human asking: why does this exist?
